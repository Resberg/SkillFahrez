# Produce a video

Define the audience, purpose, language, aspect ratio, approximate duration, platform, and intended sound. Follow a supplied script or visual direction. Resolve ordinary production details with stated assumptions; ask only for missing assets or decisions that materially prevent production.

Choose the production route from available tools: frame-driven code for reproducible motion; a compositor for layers/effects; a timeline editor for footage; image/video generation for needed shots. A missing paid voice provider does not prevent using supplied narration, another authorized provider, or an explicitly described silent treatment.

Write the script and storyboard together. Give each beat a purpose, time range, picture, movement, spoken words, caption, transition, sound, and source. Verify consequential factual claims against current owning sources. Mark illustrative or generated imagery and distinguish planned placeholders from real footage.

Choose a visual world with consistent typography, lighting, palette, and object treatment. Let the subject determine the memorable moment. Prefer showing an action or concrete example to repeating slogans. Use transitions that connect ideas; allow enough time for speech and reading.

Build the most difficult shot and transition first. For code-driven work, derive animation from the current frame or explicit time; avoid wall-clock timers, unseeded randomness, and state that depends on playback order. Revisit an earlier frame after seeking ahead to check reproducibility.

Align picture to the actual narration waveform or cue times. Keep captions readable on a phone and clear of platform overlays. Leave music below speech, avoid clipping, and place effects for specific actions. Use only authorized assets and voices.

Render a draft and inspect representative stills plus playback at normal speed. Check beginning, middle, transitions, and ending for missing assets, blank frames, text cuts, bad timing, and unreadable proof. Listen to the mix. Fix the biggest issue before adding polish.

Export the requested final format and inspect that exact file: metadata, full decode, expected duration, dimensions, and required audio. A stream's presence does not establish audible or intelligible sound. A technical pass does not establish visual quality. The optional repository video inspector assists with these checks but is not required by this installed skill.

Deliver the final file, editable source, script/captions if requested, asset credits, and a note stating what was checked and what remains uncertain. Call an unrendered project a project or preview, never a finished MP4.
