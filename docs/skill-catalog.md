# UI and video skill catalog

## Included

The four `fahrez-*` skills are independent, portable workflows. `frontend-design` is included with its supplied Apache-2.0 license. Use one main workflow per task and load specialized material only when it adds needed guidance.

The names above describe resources observed during packaging on 2026-11-13. They do not assert that another machine has the same tools or licenses. Reinstall from the owning source rather than copying cached plugin internals.

Non-UI/video skills such as career operations, security testing, and database workflows are outside this curated package. No installed skill should be treated as permission to access accounts, spend credits, deploy, or message someone.
